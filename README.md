# 📊 Conflict Discourse Analytics

### US–Israel–Iran Social Media Sentiment & Engagement Analysis

An interactive Data Science and visualization dashboard for exploring sentiment, engagement, temporal trends, topics, source labels, and statistical patterns within a **hand-made/curated dataset of 10,500 social-media records** related to US–Israel–Iran conflict discourse.

---

## 🎯 Project Overview

**Conflict Discourse Analytics** transforms a structured social-media dataset into an interactive analytical dashboard.

The project focuses on:

- Sentiment analysis
- Temporal analysis
- Engagement analysis
- Topic/search analysis
- Source-label analysis
- Statistical analysis
- Correlation analysis
- Tweet-level exploration
- Interactive filtering
- Data export

The dashboard is designed as an academic Data Science project demonstrating practical **Exploratory Data Analysis (EDA), data visualization, statistical analysis, and interactive dashboard development**.

> **Dataset Type:** Hand-made / Curated Dataset  
> **Dataset Size:** 10,500 Records

---

# ✨ Features

### 📌 Executive Dashboard

- Total posts
- Positive / Neutral / Negative posts
- Average likes
- Average retweets
- Average replies
- Average polarity
- Dynamic analytical insights

### 💭 Sentiment Analysis

- Sentiment distribution
- Polarity distribution
- Subjectivity distribution
- Polarity vs subjectivity
- Sentiment by topic
- Sentiment by source label

### 📅 Temporal Analysis

- Daily post volume
- Sentiment trends over time
- Average polarity over time
- Engagement over time
- Activity heatmap

### ❤️ Engagement Analysis

Analyze:

- Likes
- Retweets
- Replies

Includes:

- Average engagement by sentiment
- Engagement distributions
- Top posts
- Ranking by likes, retweets, and replies

### 🔎 Topic Analysis

The `Search` field is analyzed as the topic/query category recorded in the dataset.

Includes:

- Top search categories
- Topic sentiment composition
- Topic engagement
- Topic-level statistics
- Individual topic explorer

### 🏷️ Source Analysis

Analysis of the `Source Label` field provided in the dataset.

Includes:

- Source distribution
- Sentiment by source
- Engagement by source
- Source-level statistics

### 📈 Statistical Analysis

Calculated statistics include:

- Mean
- Median
- Mode
- Standard deviation
- Variance
- Minimum
- Maximum
- Q1
- Q3
- IQR

Visualizations include:

- Box plots
- Histograms
- Correlation matrix

### 🔍 Tweet Explorer

Search and explore individual records with:

- Tweet text
- Date
- Likes
- Retweets
- Replies
- Topic
- Source label
- Polarity
- Subjectivity
- Sentiment

### 📥 Data Export

Export the currently filtered dataset as a CSV file.
